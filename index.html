这不是 API 速查，也不是概念综述。全书只做一件事：把 Pi-Agent 这个 23 万行的真实 Agent 拆开，指着源码讲清楚每一层为什么这么写。Part A 先把十二个包摆到三层架构上（M01–M02）；Part B 钻进内核，看 Agent Loop 的两层循环、模型调用的十层翻译、工具锁与事件总线（M03–M07）；Part C 处理上下文：装配、压缩与会话（M08–M10）；Part D 落到运行时与生态：持久运行时、对象热重载、MCP 与 codemode、终端渲染、契约与遥测（M11–M15）。每章的代码块都标了真实文件与行号，可一键复制；三篇附录负责版本迁移对照、读源码用的 TypeScript 速查，以及把 Agent 装进你自己的服务。
